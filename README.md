# Aspira-Centralized-Placement-Portal
Centralized Placement Information and Management System | HTML, CSS, JS, Node.js, MySQL 

 Developed a full-stack web application to streamline campus recruitment processes. 
 Implemented role-based access (Admin, Student, Faculty) to handle resources,internships and jobs. 
 Implemented eligibility filtering, application tracking, shortlistings and timeline tracking. 
 Enabled real-time notifications, reports and analytics.
